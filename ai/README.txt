Generative AI tools were utilized in the preparation of this assignment.

**1. AI Tool(s) Used:**
* ChatGPT 4.0 (https://chat.openai.com/)
* Claude Sonnet 4.5 (https://claude.ai/)

**2. Description of Use:**
I used the specified AI tool to do these tasks:
- Generate Javadoc comments for classes and methods that were missing them.
- Analyze existing JUnit Tests in test/scenarios/ to understand the pure behavior test that they used.
- Create the baseline of PigeonTest focusing on mutation testing before I expanded it further.

The primary purpose of this was to ensure the submission conforms to the Javadoc requirements specified by the course checkstyle configuration (`https://csse2002.uqcloud.net/checkstyle.xml`).

**3. Process:**
The AI was provided with enemies' specification and prompted to create the corresponding Javadoc documentation and the initial baseline of JUnit Test (PigeonTest).

All AI-generated comments were manually reviewed and, where necessary, edited to ensure they were accurate and correctly described the code's functionality, parameters, return values, and any exceptions.
