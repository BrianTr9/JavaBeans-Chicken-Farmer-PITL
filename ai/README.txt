Generative AI tools were utilized in the preparation of this assignment.

**1. AI Tool(s) Used:**
* ChatGPT 4.0 (https://chat.openai.com/)

**2. Description of Use:**
I used the specified AI tool to generate Javadoc comments for classes and methods that were missing them.

The primary purpose of this was to ensure the submission conforms to the Javadoc requirements specified by the course checkstyle configuration (`https://csse2002.uqcloud.net/checkstyle.xml`).

**3. Process:**
The AI was provided with specific code snippets (e.g., a method signature and its body, or a class definition) and prompted to create the corresponding Javadoc documentation.

All AI-generated comments were manually reviewed and, where necessary, edited to ensure they were accurate and correctly described the code's functionality, parameters, return values, and any exceptions.
